# Family VPN — rebuild backlog

Цель: с нуля развернуть семейный VPN на двух независимых узлах (Литва и
Финляндия), оставить управляющий сайт и Telegram-бот на литовском узле и
выдавать каждому устройству один отзываемый Xray-профиль.

## Принятые решения

- Клиенты: **Npv Tunnel** для российского App Store, **NapsternetV** для
  Android и Hiddify для настольных систем.
- Базовый транспорт: VLESS Vision + Reality на TCP/443.
- В профиле одновременно находятся два edge: `🇱🇹 Литва 🚀` и
  `🇫🇮 Финляндия 🚀`; встроенный balancer выбирает доступный узел.
- Российские домены, российский DNS и локальные сети идут напрямую с
  устройства. Остальной трафик идёт через выбранный edge.
- Один родственник — одно активное устройство. Один профиль нельзя безопасно
  превратить в два: revoke удаляет его на обоих edge.
- Control plane не хранит открытый subscription-token и не пишет VPN-реквизиты
  в логи или Telegram.

## Критерии готовности

1. Новый пользователь устанавливает предложенный для платформы клиент, нажимает одну кнопку на сайте и
   подключается без ручной правки JSON.
2. При отключении любого одного edge зарубежные сайты продолжают открываться.
3. `.ru`, банки, Госуслуги и локальная сеть видят обычный IP пользователя.
4. Telegram, YouTube и Cloudflare открываются через VPN; DNS не утекает в
   провайдера для proxy-доменов.
5. После revoke ни один из двух edge не принимает профиль.
6. Повторный клик активации, сетевой timeout и повторный deploy не создают
   дубликатов и не оставляют частично активное устройство.
