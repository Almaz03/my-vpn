# Архитектура

Публичный Caddy принимает HTTPS на TCP 443 и проксирует портал на `127.0.0.1:8080`. Go-приложение управляет приглашениями, запросами доступа, Telegram-ботом и SQLite.

VPN data plane — существующий Docker-контейнер `amnezia-awg2`: интерфейс `awg0`, UDP 35473, конфигурация `/opt/amnezia/awg/awg0.conf`. Непривилегированное приложение вызывает только root-owned `amneziawg-helper` через точное sudoers-правило. Helper создаёт уникальный private key, PSK и `/32` на устройство, атомарно добавляет peer и сохраняет root-only клиентский `.conf`.

Ссылка `/s/{token}` хранится в SQLite только как HMAC, действует год и немедленно инвалидируется при отзыве устройства. QR содержит тот же индивидуальный `.conf`.
