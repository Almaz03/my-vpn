# Безопасность

- Одно активное устройство на нормализованное имя клиента.
- Один уникальный private key и PSK на устройство; секретные профили имеют режим `0600`.
- Коды одноразовые, живут не более часа и не передаются в URL.
- Сырые subscription-токены не хранятся; в SQLite находится HMAC.
- Активация, запросы доступа и polling ограничены по частоте.
- Telegram доступен только allowlist администраторов.
- Caddy не пишет access log, содержащий `/s/{token}`.
- Приложение непривилегированное; sudo разрешает только фиксированный AmneziaWG helper.
- Backup шифруется `age` и содержит SQLite, runtime env, серверный AWG config и клиентские профили.

Секретные `.conf`, ключи, токены и коды нельзя отправлять в чат, commit или журнал.
