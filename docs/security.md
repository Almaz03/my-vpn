# Безопасность

- Одно активное устройство на нормализованное имя клиента.
- Один уникальный VLESS UUID на устройство, атомарно установленный на оба edge; root-only state имеет режим `0600`.
- Коды одноразовые, живут не более часа и не передаются в URL.
- Сырые subscription-токены не хранятся; в SQLite находится HMAC.
- Активация, запросы доступа и polling ограничены по частоте.
- Статистика клиентов содержит только агрегированные байты, время активности и выбранный edge. История сайтов, DNS-запросы и адреса назначения не записываются; почасовые агрегаты автоматически удаляются через 62 дня.
- Telegram доступен только allowlist администраторов.
- Caddy не пишет access log, содержащий `/s/{token}`.
- Приложение непривилегированное; sudo разрешает только фиксированный dual-edge helper.
- Удалённое управление использует отдельный SSH login, pinned host key и фиксированную sudo-команду без shell-доступа.
- Backup шифруется `age` и содержит SQLite, runtime env и серверную Xray-конфигурацию; открытые subscription-токены не сохраняются.

UUID, приватные ключи Reality, subscription-токены и коды нельзя отправлять в чат, commit или журнал.
