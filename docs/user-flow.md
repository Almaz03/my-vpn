# Сценарий пользователя

1. Нажать «Запросить доступ» на сайте и указать имя, устройство и платформу.
2. Дождаться решения администратора; повторный запрос не создаётся.
3. После одобрения скопировать часовой код и ввести его на сайте.
4. Установить AmneziaVPN.
5. Скачать `family-vpn.conf` либо отсканировать QR-код и импортировать профиль.
6. Подключить профиль и проверить внешний сайт.

Для замены телефона администратор сначала отзывает старое устройство. Копировать один профиль на несколько устройств нельзя.
